#  Portafolio de Dashboards y Análisis de Datos

Portafolio de proyectos de análisis de datos, visualización y desarrollo de tableros interactivos.

##  Proyectos Disponibles

### 1. 🇨🇴 Calidad del Aire en Colombia (2011–2025)
* **Descripción:** Análisis exploratorio, proceso ETL y tablero interactivo basado en datos abiertos del IDEAM para evaluar contaminantes y tendencias históricas.
* **Tecnologías:** Python (Pandas, Plotly), Streamlit, Git.
* **Archivos:** Carpeta `/calidad-aire-colombia` (`app.py`, datos limpios y dependencias).

### 2. Inequidad Educativa
* **Descripción:** Tablero analítico enfocado en métricas y visualización de brechas educativas.
* **Herramienta:** Power BI.
* **Carpeta:** `/inequidad-educativa`.
